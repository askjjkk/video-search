# video-search: поиск слов и фраз в видеоархиве

Программа для Windows (консоль), которая **локально** распознаёт речь в видео (Whisper), запоминает слова с таймкодами и потом ищет по ним слова и фразы. Найденные ролики можно скопировать в отдельную папку. Интернет нужен только один раз, чтобы скачать модель распознавания.

Это рабочий прототип: проверен на коротких тестовых роликах (синтезированная речь). Скорость на больших архивах зависит от компьютера и модели, точные цифры не заявляются.

## Что умеет
- **Распознавание речи** во всех видео папки (faster-whisper, русский язык). Индекс сохраняется в SQLite, можно прервать и запустить снова: уже обработанные файлы пропускаются.
- **Поиск слов и фраз с учётом словоформ**: запрос `кошка` найдёт «кошки», «кошек». Поддерживается маска `кошк*`. Фраза ищется как слова подряд.
- **Копирование** найденных роликов в папку и файл `результат.csv` (файл, время, контекст).
- **Отчёт**: дубли (по отпечатку файла), ролики без речи (музыка, природа), иностранные ролики. Ничего не удаляется.

## Установка
Нужен Python 3.10+ (проверено на 3.14).
```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```
ffmpeg не нужен: звук читает библиотека PyAV.

## Использование
```
.venv\Scripts\python.exe videosearch.py index D:\video --model small
.venv\Scripts\python.exe videosearch.py search "кошк*" --db D:\video --out D:\found
.venv\Scripts\python.exe videosearch.py report --db D:\video --out D:\sorted
```
- `index` создаёт файл `video_index.db` в папке с видео (или там, куда указывает `--db`).
- Модели: `tiny`, `base`, `small` (по умолчанию), `medium`, `large-v3`. На слабом ПК без видеокарты берите `base` или `tiny`, на видеокарте NVIDIA добавьте `--device cuda`.
- Язык определяется по первым 30 секундам: нерусские ролики помечаются и не расшифровываются.

## Тестовые данные
`make_test_data.py` создаёт несколько коротких роликов с озвучкой голосами Windows, чтобы проверить работу без чужих файлов (нужны русский и английский голоса Windows).

## Известные особенности
- Версию `av` нужно держать 15.1.0: более новые несовместимы с faster-whisper 1.2.1.
- Качество распознавания зависит от модели и качества звука.
- Это прототип: нет окна запуска и нечёткого поиска (с опечатками).
